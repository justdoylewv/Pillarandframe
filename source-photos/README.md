# Source photos

Original, full-resolution photography as delivered. Nothing in here is served
by the site.

`Website_Photos.zip` is the untouched archive. The web versions live in
`public/photos` as WebP, resized and compressed with sharp at quality 82 and
capped at each file's native width so nothing is upscaled.

To add or replace a photo: drop the original in a new archive here, export a
WebP into `public/photos`, and point `lib/content/photos.ts` at the new path.
